# About ImGui Library

This folder contains files from the [Dear ImGui Open-Source Library](https://github.com/ocornut/imgui). This library provides great functionality for implementing UI (including text, sliders, buttons, and more input options) into a preexisting application. If working with ImGui on this project, it's recommended to read the comments in `imgui.h`, `imgui_impl_vulkan.h`, and maybe `imgui_impl_glfw.h` beforehand.

For this project, [this example](https://github.com/ocornut/imgui/tree/master/examples/example_glfw_vulkan) from the above repository was used to implement ImGui into the game engine due to it using GLFW and Vulkan as this project also uses.
